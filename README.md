# Edge-to-Cloud IoT Framework for Smart Agriculture

A 3-layer IoT framework (Edge, Fog, Cloud) designed for automated and predictive irrigation using AWS services and machine learning.

## Explore the Project
For a comprehensive breakdown of the system architecture, cloud data pipelines, SQL routing rules, and ML models, please visit my portfolio website:
👉 **[View Full Project Details & Documentation](https://remaabdullah.github.io/Portfolio/EdgeToCloudIoTFramework.html)**

## Repository Contents
- `edge_device_logic.ino`: Arduino code for sensor data acquisition, filtering, and edge computing logic.
- `sensor_payload_schema.json`: Unified JSON payload schema for device-to-cloud communication.
- `aws_iot_routing_rule.sql`: AWS IoT Core Rules Engine query for real-time alerting.
- `iot_analytics_preparation.sql`: SQL queries for data cleansing and ML dataset preparation.
- `ml_inference_output.json`: JSON output structure for predictive irrigation.
